# Template Caption & Balasan Threads

Tukar `[...]` dengan maklumat barang. Jangan copy-paste ayat sama ke banyak tempat, ubah sikit setiap kali. Ayat yang sama berulang-ulang buat sistem tandakan akaun kau sebagai spam.

> **Peraturan emas:** Bagi nilai dulu, baru link. Setiap post atau balasan mesti boleh berdiri sendiri walaupun tanpa link.

---

## 1. Balas orang yang tanya / cari barang

**A. Pengalaman sendiri**
```
Aku guna [nama barang] dah [tempoh]. Okay untuk [kegunaan dia sebut].
Plus: [kelebihan 1], [kelebihan 2]
Minus: [kelemahan jujur]
Harga dalam RM[harga]. Ni link aku beli (link affiliate): [link]
```

**B. Bagi pilihan (lebih dipercayai)**
```
Ikut bajet kau:
• Bawah RM[x]: [barang A], cukup untuk basic
• RM[x]–RM[y]: [barang B], paling berbaloi
• Nak yang tahan lama: [barang C]
Aku letak link B kat bawah sebab tu yang aku rasa paling ngam (link affiliate): [link]
```

**C. Pendek & santai**
```
Try [nama barang], harga RM[harga] je, review pun banyak ok ([jumlah] terjual). Link (affiliate): [link]
```

**D. Kalau tak pasti barang tu sesuai**
```
Bergantung, kau nak guna untuk [A] ke [B]? Kalau [A], [barang] ni okay. Kalau [B] baik cari yang ada [ciri].
```
*(Tak perlu link pun. Bina kepercayaan dulu, nanti orang tanya sendiri.)*

---

## 2. Post content sendiri

**Listicle**
```
[Nombor] barang [kategori] bawah RM[harga] yang betul-betul berbaloi 🧵

1. [Barang 1]: [kenapa bagus, 1 ayat]
2. [Barang 2]: [kenapa bagus]
3. [Barang 3]: [kenapa bagus]

Link semua kat komen / bio (affiliate) 👇
```

**Review jujur**
```
Review jujur [nama barang] lepas guna [tempoh]:
✅ [kelebihan]
✅ [kelebihan]
❌ [kelemahan]
Berbaloi? [jawapan + untuk siapa sesuai].
```

**Before / after / masalah → solusi**
```
Dulu [masalah], penat gila. Sejak guna [barang], [hasil].
Tak sangka barang RM[harga] boleh ubah [rutin].
```

**Musim sale**
```
[11.11 / 12.12 / Payday] ni aku dah list barang yang memang turun harga, bukan "diskaun palsu":
• [Barang]: RM[lama] → RM[baru]
• [Barang]: RM[lama] → RM[baru]
Voucher claim dulu sebelum checkout. Link (affiliate) kat bio.
```

**Soalan untuk engagement (tanpa link)**
```
Apa satu barang Shopee bawah RM50 yang korang rasa paling berbaloi pernah beli? Aku mula dulu: [barang] 👇
```

## 4. Benda yang JANGAN buat
- ❌ Komen link je tanpa ayat
- ❌ Balas post yang langsung tak tanya pasal barang
- ❌ Post benda sama 10 kali sehari
- ❌ Puji barang yang kau tak pernah tengok review dia
- ❌ Sorok yang tu link affiliate
