# Shopee Affiliate Toolkit

| Fail | Guna untuk |
|---|---|
| `template-caption.md` | Template balasan & post Threads (BM santai) |
| `content-plan-30-hari.md` | Jadual post 30 hari + rutin harian |
| `tracker.csv` | Rekod barang, link, tempat share, klik, order, komisen (buka dengan Excel / Google Sheets) |
| `index.html` | Page "link in bio" senarai semua barang affiliate kau |

## Langkah mula
1. **Daftar Shopee Affiliate**: app Shopee → Saya → Shopee Affiliate Program (atau affiliate.shopee.com.my). Tunggu lulus.
2. **Ambil link**: buka produk → Share → salin link affiliate.
3. **Isi page link-in-bio**: buka `index.html`, edit bahagian `PROFIL` dan `BARANG` sahaja.
4. **Publish page** (percuma) guna GitHub Pages: Settings → Pages → pilih branch → folder. Letak URL tu kat bio Threads/IG.
5. **Ikut content plan** & update tracker setiap malam.

## Peraturan supaya akaun selamat
- Cakap terus terang itu link affiliate.
- Balas hanya bila orang memang tanya / cari barang.
- Jangan post link sama berulang-ulang dalam masa singkat.
- Baca terma Shopee Affiliate. Spam, beli guna link sendiri, dan iklan palsu boleh buat komisen dibatalkan.
